# Chat interactivo en tiempo real
Objetivo: practicar JavaScript lado‑servidor con Node.js y Socket.io.
Permite que varios usuarios intercambien mensajes al mismo tiempo.

## Tecnologías
‑ Node.js
‑ Express
‑ Socket.io
‑ HTML y CSS

## Despliegue
Se sube primero el código a GitHub, luego se conecta el repositorio a Heroku para publicar el servidor.
